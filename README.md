# 📝 Todo List Web Application

A simple and interactive Todo List application built using HTML, CSS and JavaScript to manage daily tasks and improve productivity.

## 🚀 Features

- ➕ Add new tasks.
- 🗑️ Delete tasks.
- ⌨️ Press Enter to add tasks.
- 🔢 Automatically updates the total task count.
- 🎨 Simple and clean user interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
Todo-List/
│
├── tod.html
├── tod.css
└── tod.js
```

## ⚙️ How to Run

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Open the project folder.
3. Open `tod.html` in your web browser.
4. Start adding and managing your tasks.

## 💡 Project Description

This project demonstrates the use of JavaScript DOM manipulation and event handling to create an interactive web application.

Users can add tasks, delete completed or unwanted tasks, and view the updated task count dynamically.
